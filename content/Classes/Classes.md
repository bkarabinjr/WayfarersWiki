Chapter 4. Wayfarers has **16 base classes**, grouped into four [[Class Roles|roles]]. Each class has a base toolkit, abilities unlocked by [[Tiers|tier]], and a set of [[Subclasses]]. Some advanced paths are [[Prestige Classes]].

| Role | Classes |
|---|---|
| **Vanguard** (warriors) | [[Berserker]], [[Soldier]], [[Martial Artist]], [[Guardian]] |
| **Paragon** (mages) | [[Arcanist]], [[Cleric]], [[Druid]], [[Psion]] |
| **Specialist** (experts) | [[Artisan]], [[Sage]], [[Ranger]], [[Rogue]] |
| **Gifted** (support) | [[Bard]], [[Duskblade]], [[Sorcerer]], [[Warlock]] |

## How far along each class is

| Class | Status in the source |
|---|---|
| [[Berserker]] | Full base class plus one full subclass ([[Fury of the Bloodrager]]) |
| [[Soldier]] | Full chassis, tier ability names, one full subclass ([[Valor of the Gunslinger]]), maneuver list |
| [[Ranger]] | Many features and a subclass draft ([[Beastcaller]]) |
| [[Guardian]] | Features and tier ability names |
| [[Druid]] | Chassis and core features |
| [[Bard]] | Chassis and Bardic Inspiration |
| [[Arcanist]] | A few tier abilities |
| [[Rogue]], [[Warlock]] | One or two abilities |
| [[Cleric]], [[Martial Artist]], [[Sorcerer]] | Template only |
| [[Psion]], [[Artisan]], [[Sage]], [[Duskblade]] | Role description and subclass names only |

All classes follow the [[Class Template]].

> [!note] Wizard
> A "Wizard" appears in the expansion subclass list. The Arcanist is described as "previously the Wizard", so those ideas are filed under [[Arcanist]].
