Every class in the source is built on the same skeleton. Copy this outline when starting a class page.

```
[Class Description]

Primary Abilities:
Hit Points / Class Dice:

Proficiencies
  Ability Proficiency Level Increase (Choose Two):
  Skills (Choose Two):
  Weapons:
  Tools:
  Armor:

Class Features
  Resources:
  Class Kit:

Tier 1          (about 10–12 abilities to choose from)
Tier 2          (+1 Action Point, subclass feature)
  [New Social Skill]
  [New Exploration Skill]
  [Upgraded Exploration Skill]
  [Upgraded Combat Skill]
  [Upgraded Combat Skill]
Tier 3          (+1 Action Point, subclass feature)
Tier 4          (+1 Action Point, subclass feature)

Subclasses (4–5)
```

## Notes

- Tier abilities are drafted as checkbox lists: players pick from them as they level. The [[Soldier]] draft says "two skills per level, new tiers unlock at levels 6, 11 and 16."
- Every tier from 2 up is meant to include a new social skill, a new exploration skill, an upgraded exploration skill and two upgraded combat skills, so every class can engage all three [[Design Pillars]].
- Tiers 2, 3 and 4 each add an [[Action Points|Action Point]] (4th, 5th and 6th).
