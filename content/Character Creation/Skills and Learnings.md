Each [[Attributes|attribute]] has two core skills. On top of those, characters can train **learnings**: specialized trained skills, [[Knowledge Learnings|knowledges]] and [[Craft Learnings|crafts]].

## Core skills

| Attribute | Skills |
|---|---|
| Might | Athletics, Intimidation |
| Dexterity | Acrobatics, Subterfuge |
| Intelligence | Analysis, Survival |
| Wisdom | Awareness, Insight |
| Presence | Influence, Performance |
| Resolve | Concentration, Composure |
