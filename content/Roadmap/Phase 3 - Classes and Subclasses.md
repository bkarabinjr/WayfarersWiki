**Goal:** bring all 16 classes up to the same standard. See [[Class Completion Tracker]] for where each class stands today.

**Milestones:** 5 classes for M2 (Alpha 1), all 16 at Tiers 1–2 for M3, all 16 at Tiers 1–4 for M4.

## Set the standard first

- [ ] Agree on the class structure: how many picks per tier, what the "New/Upgraded Social, Exploration, Combat Skill" slots mean → [[Class Template]]
- [ ] Decide how many subclasses each class launches with (4 or 5)
- [ ] Settle subclass prefixes: Curriculum/Academy, Domain/Prayer, Circle/Grove, Heritage/Soul → [[Subclasses]]
- [ ] Settle class resources: Soldier (Valor vs superiority dice), Rogue (Schemes vs Panache), shared focus points for Psion / Martial Artist / Sorcerer → [[Soldier]], [[Rogue]], [[Sorcerer]]
- [ ] Decide on multiclassing, or rule it out → [[Multiclassing]]
- [ ] Define prestige classes and the reward for staying single-class → [[Prestige Classes]]
- [ ] Use [[Berserker]] as the reference class: finish it first, then match the others to it

## Alpha 1 classes (one per role, plus the two most complete)

- [ ] [[Berserker]]: fill the open T1–T4 slots, fix legacy terms, add exploration and social hooks
- [ ] [[Soldier]]: write rules text for all named traits, fighting styles and the maneuvers → [[Soldier Maneuvers]]
- [ ] [[Ranger]]: pick one Favored Enemy version, replace the sci-fi terrain, write the chassis
- [ ] [[Druid]]: write Nature's Gift, the Wild Shape forms list, and T1–T2
- [ ] [[Bard]]: write Spotlight, Encore and T1–T2

## Remaining classes

- [ ] [[Guardian]]: chassis, Harness Divinity numbers, smite rules text
- [ ] [[Arcanist]]: chassis, Scripts resource, stored spells
- [ ] [[Cleric]]: chassis, Divinity and Prayer features
- [ ] [[Martial Artist]]: chassis, Focus resource, pick one subclass list
- [ ] [[Rogue]]: chassis, resource, Veil of Shadows
- [ ] [[Sorcerer]]: Strain / Soul Motes, familiar health-sharing, signature spells
- [ ] [[Warlock]]: pacts, hexes, invocations
- [ ] [[Psion]]: dual spell modifiers, a psionic resource
- [ ] [[Artisan]]: the Projects crafting system
- [ ] [[Sage]]: buffs, barriers and debuffs kit
- [ ] [[Duskblade]]: decide light vs heavy armor, half-caster rules

## Subclasses

- [ ] Write one subclass per class for Alpha 2 (Berserker, Soldier and Ranger already have one: [[Fury of the Bloodrager]], [[Valor of the Gunslinger]], [[Beastcaller]])
- [ ] Write the remaining launch subclasses for Beta
- [ ] Move the long expansion lists to a later-expansion page once the launch set is chosen

## Exit criteria

- Every class meets the definition of done on [[Class Completion Tracker]].
- A quick balance pass: each class's damage, defense and utility at each tier compared in one table.
