The plan for taking Wayfarers from the Master Document V01 to a finished, playable game. The work is split into eight phases. Each phase has its own page with a checklist. Tick items off by changing `- [ ]` to `- [x]` (or clicking the checkbox in Obsidian), and [[Roadmap Progress]] updates on the next site build.

## The path to 1.0

| Phase | Goal | Depends on |
|---|---|---|
| [[Phase 1 - Lock the Core Rules]] | Settle the engine: the core die, Action Points, attributes, defense, tiers and levels | — |
| [[Phase 2 - Character Foundations]] | Finish attributes, skills, backgrounds, lineages and the character sheet | Phase 1 |
| [[Phase 3 - Classes and Subclasses]] | Bring all 16 classes up to the same standard | Phases 1–2 |
| [[Phase 4 - Magic and Spells]] | Build the cooldown spell system, spell tags and the spell list | Phase 1 |
| [[Phase 5 - Equipment and Feats]] | Weapons, armor, items, and a cleaned-up feat catalog | Phase 1 |
| [[Phase 6 - GM Toolkit]] | Encounters, creatures, exploration, downtime and rewards | Phases 1, 3 |
| [[Phase 7 - Playtesting]] | Alpha and beta playtests, feedback, iteration | Varies by alpha |
| [[Phase 8 - Production and Release]] | Writing pass, originality review, layout, art and publishing | Phase 7 |

Phases 3, 4 and 5 can run in parallel once Phase 1 is locked. Splitting them between collaborators is the fastest way through.

## Milestones

| Milestone | What it means | Target date |
|---|---|---|
| **M1: Core locked** | Every Phase 1 question answered and written into the rules pages | *set a date* |
| **M2: Alpha 1** | A Tier 1 one-shot playable with 5 classes, 5 lineages and a starter spell list | *set a date* |
| **M3: Alpha 2** | All 16 classes playable at Tiers 1–2, one subclass each | *set a date* |
| **M4: Beta** | Tiers 1–4, the full spell list, a starter bestiary and the GM chapters | *set a date* |
| **M5: 1.0** | Edited, laid out, reviewed for originality, and released | *set a date* |

The designer's own "Next Alpha" goal is M2: *full implementation of the mechanics, to test which ones work well together, which need more work, and which to drop.*

## Current focus

What the designer listed as in progress in the master document:

- Reducing the number of spells and creating a working **spell tag** system → [[Phase 4 - Magic and Spells]]
- Feats that level up, giving a move a visible progression path → [[Phase 5 - Equipment and Feats]]
- A more interesting armor and weapon system → [[Phase 5 - Equipment and Feats]]
- A more interesting health and status management system → [[Phase 1 - Lock the Core Rules]]

## Tracking tools

- [[Open Questions]] lists every unresolved design question in the wiki. Most of Phase 1 is working through it.
- [[Roadmap Progress]] shows how many tasks are done in each phase.
- [[Decision Log]] records each call once it's made, so nobody reopens a settled question.
- [[Class Completion Tracker]] shows where each of the 16 classes stands.
- [[Naming and Originality Review]] tracks names and text that need replacing before release.
