**Goal:** a working cooldown-based spell system and a spell list under 300 spells. See [[Spellcasting]] for the design intent.

**Milestones:** a starter spell list for M2, all Tier 1–2 spells for M3, the full list for M4.

## System

- [ ] Write the cooldown rules: how long, how they're tracked, what resets them
- [ ] Set spells known: cantrips from the spell attribute, 2 spells per tier for full casters, 1 for half casters → [[Spellcasting]]
- [ ] Define the spell lists (Arcane, Divine, Primal, Occult, Psionic, Universal?) and which classes use which
- [ ] Design the **spell tag** system that replaces classic descriptors (in progress)
- [ ] Rework the spell schools
- [ ] Assign an attribute to every spell and define the crit options per attribute
- [ ] Define upcasting, and which spells can
- [ ] Write the spell timing rules (bonuses for acting before or after others) → [[Spellcasting]]
- [ ] Write metamagic for the [[Arcanist]] and [[Sorcerer]]
- [ ] Define spell DC, spell attack and "spell power"
- [ ] Define concentration and casting defensively (used by War Caster) → [[Skill Feats]]
- [ ] Confirm the area shapes → [[Areas of Effect]]

## Spell list

- [ ] Agree on a spell entry format (name, tier, tags, attribute, AP cost, cooldown, range, area, effect, upcast)
- [ ] Write the Alpha 1 starter set (about 20–30 spells covering the Druid and Bard)
- [ ] Write the smites for the [[Guardian]] → [[Spells]]
- [ ] Write Hunter's Mark and Conjure Volley for the [[Ranger]]
- [ ] Write all Tier 1–2 spells for Alpha 2
- [ ] Write Tier 3–4 spells for Beta, staying under 300 total
- [ ] Write the Wild Surge table → [[Appendix Notes]]

## Exit criteria

- Every caster class can pick spells for Tiers 1–4.
- A playtest shows cooldowns aren't trivial (casters aren't casting everything every round).
