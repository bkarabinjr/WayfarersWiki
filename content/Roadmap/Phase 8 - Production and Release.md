**Goal:** turn the wiki into a finished book (or PDF) that can be shared or sold.

## Writing

- [ ] Write a style guide: voice, terms, how rules text is phrased
- [ ] Editing pass on every chapter for consistent terms
- [ ] Write the introduction: *What you need to play* and *How to Play*
- [ ] Fill in the [[Glossary]]
- [ ] Write example-of-play sidebars for combat, exploration and social scenes

## Originality

- [ ] Work through the [[Naming and Originality Review]]
- [ ] Rewrite any text that closely follows another game's wording

## Book

- [ ] Decide the format: free PDF, pay-what-you-want, print, crowdfunding
- [ ] Choose a layout tool and template
- [ ] Commission or create art, with a cover first
- [ ] Final character sheet design
- [ ] Quickstart rules (a free, short intro version is a common way to find players)
- [ ] Choose a license for the game (and for any third-party content)
- [ ] Choose a storefront or host and prepare the page

## Launch

- [ ] Release
- [ ] Set up a way to collect errata and questions
- [ ] Plan the first expansion (extra lineages and subclasses from the idea lists)
