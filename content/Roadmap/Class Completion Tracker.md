**Chassis** means primary abilities, Class Dice, and proficiencies.

## Definition of done for a class

A class is ready for playtesting when:

- Chassis is complete: primary abilities, Class Dice, all five proficiency lines
- Class resource and class kit are written with exact numbers
- Every tier has its full set of picks written, with no "?" slots
- Every tier from 2 up has its social, exploration and combat skill slots filled
- It has at least one exploration hook and one social hook
- It uses only current terms (attribute names, damage types, conditions)
- It has at least one complete subclass
- Someone has built a character with it and played a session

*To track a class against this list, copy it onto the class page as a checklist (`- [ ]` items).*
