**Goal:** find out which mechanics work together, which need work, and which to drop, then iterate.

## Alpha 1 (milestone M2)

**Scope:** Tier 1 only. Classes: [[Berserker]], [[Soldier]], [[Ranger]], [[Druid]], [[Bard]] (one per role, plus the two most complete). Lineages: [[Therian]], [[Stoutfolk]], [[Sylvar]], [[Human]], [[Taruk]]. About 20–30 spells and 10 creatures.

- [ ] Assemble the playtest packet: core rules summary, 5 pregenerated characters, sheet, starter spells
- [ ] Write a short one-shot adventure with one of each scene type: conflict, interlude, GM scene
- [ ] Include at least one skill challenge and one exploration event
- [ ] Write a feedback form: fun, clarity, turn speed, rounds per fight, confusing rules
- [ ] Run with the core group
- [ ] Run with at least one group that has never seen the rules
- [ ] Time each combat round and count rounds per fight against the 2–3 / 4–5 / 6–8 targets
- [ ] Log findings and record resulting changes in the [[Decision Log]]

## Alpha 2 (milestone M3)

- [ ] All 16 classes at Tiers 1–2, one subclass each
- [ ] Run a two- or three-session mini campaign that crosses from Tier 1 to Tier 2
- [ ] Test tier advancement, feats and the secret check-in
- [ ] Balance pass across all classes

## Beta (milestone M4)

- [ ] Full Tiers 1–4, full spell list, starter bestiary
- [ ] Open the beta to a wider group of outside playtesters
- [ ] Test high-tier play (Tier 4 "fully realized characters")
- [ ] Final balance pass and errata

## Exit criteria

- Two or more outside groups have played through without the designer explaining rules.
- The open questions list is empty.
